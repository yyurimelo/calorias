# Instruções do Projeto

Regras que TODOS os assistentes de IA devem seguir sempre, em toda tarefa:

## Idioma
- Responder sempre em português (pt-BR).

## Git / Commits
- NUNCA adicionar o trailer "Co-authored-by" (nem qualquer variação de co-agent) nos commits.
- Só criar commits quando o usuário pedir explicitamente.

## Formatação de código
- Após editar ou gerar qualquer código, SEMPRE rodar `npm run format` para identar e formatar os arquivos.
- Nunca entregar código sem formatação ao terminar uma tarefa.
